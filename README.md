# Inventory Management System

A beginner-friendly C++ console application for tracking inventory items. It demonstrates object-oriented design, vectors, file handling, input validation, searching, sorting, and simple reporting.

## Features

- Add new inventory items
- View all items in a formatted table
- Search by item id or name
- Update item quantity and price
- Delete items
- Sort inventory by name, quantity, or total value
- Save and load inventory data from a CSV file
- Generate low-stock and total-value reports
